# SHPE Northeastern Website Style Guidelines v1.0 (Draft)

## Purpose
Provide a shared visual foundation for all SHPE Northeastern website contributors while allowing flexibility in page-specific content and layouts.

---

## Typography

### Recommended Direction
Use the official SHPE font where possible.

If the official SHPE font cannot be implemented or supported within the project stack, use the following fallback fonts:

- Helvetica
- Arial

Maintain a consistent heading hierarchy across all pages and use the same font family throughout the website.

### Heading Structure

**H1 - Page Titles**
- Desktop: 48px
- Mobile: 32px
- Font Weight: Bold (700)

**H2 - Section Headers**
- Desktop: 32px
- Mobile: 26px
- Font Weight: Bold (700)

**H3 - Subsection Headers**
- Desktop: 24px
- Mobile: 20px
- Font Weight: Semibold (600)

**Body Text**
- Font Size: 16px
- Font Weight: Regular (400)
- Line Height: 1.6

**Note:** Typography sizing may be adjusted during implementation if needed.

## Accessibility Requirements

All pages should:
- Use adequate color contrast.
- Include alt text for images.
- Be mobile responsive.
- Use semantic heading structures.
- Support keyboard navigation where applicable.
