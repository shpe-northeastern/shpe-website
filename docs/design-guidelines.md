## Accessibility Requirements

All pages should:
- Use adequate color contrast.
- Include alt text for images.
- Be mobile responsive.
- Use semantic heading structures.
- Support keyboard navigation where applicable.

---

## Reusable Components

Before creating a new component, contributors should check whether one already exists for:

- Navbar
- Footer
- Buttons
- Cards
- Section Headers

---

## Notes for Contributors

Individual page owners are responsible for:
- Page layout
- Page content
- Feature implementation
- Unique page requirements

These guidelines are intended to create consistency, not restrict creativity.
